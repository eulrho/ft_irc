# ft_irc

## 📄 프로젝트 소개
이 프로젝트의 목표는 상용 클라이언트와 통신이 가능한 IRC(Internet Relay Chat) 서버를 구현하는 것입니다.
<br></br>
상용 클라이언트 irssi와 irc 서버 inspircd, 그리고 RFC 1459를 기준으로 개발되었습니다.

## 📌 제약 조건
- C++98 규격으로 작성하고 -Wall -Wextra -Werror 플래그로 컴파일해야 함
- 외부 라이브러리(Boost 포함)는 금지됨
- 클라이언트와의 연결이 안정적이어야 함
- 반드시 Makefile을 제공하며 $(NAME), all, clean, fclean, re 규칙을 포함해야 함
- 모든 I/O는 논블로킹, fork 금지, 하나의 poll()(또는 동등 기능)로 read/write/listen 처리. 필요 시 select(), kqueue(), epoll() 사용 가능.
- poll() 없이 read/recv나 write/send를 시도하면 감점(0점)
- 통신은 TCP/IP(v4 또는 v6) 사용
- 평가 시 사용할 레퍼런스 IRC 클라이언트를 선정해야 하며, 해당 클라이언트가 오류 없이 서버에 접속 가능해야 함
- 동작은 공식 IRC 서버와 유사해야 합니다.


## 🛠️ 주요 기능
#### 필수 상호작용
- 채널 브로드캐스트: 한 클라이언트가 채널에 보낸 메시지는 해당 채널의 모든 다른 참여자에게 전달됨
- 사용자 권한 계층: 오퍼레이터(운영자) 와 일반 사용자 구분

#### 명령어
| 명령어 | 설명 | 채널 운영자 전용 여부 |
| --- | --- | --- |
| PASS | connection password 설정. 서버에 지정된 password 확인용 | X |
| NICK | nickname 설정 | X |
| INVITE | 사용자를 채널로 초대 | O |
| USER | 새 사용자의 사용자 이름, 호스트 이름, 실제 이름 지정 | X |
| MODE | 채널 모드 설정 | O |
| QUIT | 종료 메시지와 함께 클라이언트 세션 종료 | X |
| JOIN | 사용자가 특정 채널에 참여하거나 생성하도록 요청 | X |
| PART | 메시지를 보낸 사용자를 모든 채널의 활성 멤버 목록에서 제거 | X |
| TOPIC | 채널의 주제를 조회하거나 변경 | O |
| KICK | 채널에서 사용자를 강제로 제거하도록 요청 | O |
| PRIVMSG | 사용자 간 개인 메시지를 보내거나 채널에 메시지를 보내는 데 사용 | X |
| NOTICE | PRIVMSG와 비슷 | X |
| SENDFILE | 다른 사용자에게 파일 송신(**Bonus**) | X |
| GETFILE | 다른 사용자로부터 파일 수신(**Bonus**) | X |
| [봇 이름] | 서버에 대한 다양햔 유형 정보를 제공하는데 도움이 되는 봇(**Bonus**) | X |

#### 명령어 MODE 옵션
| 옵션 | 설명 |
| --- | --- |
| i | 초대 전용 채널 토글 |
| t | TOPIC 명령을 운영자 전용으로 제한 토글 |
| k | 채널 키(비밀번호) 설정/해제 |
| o | 운영자 권한 부여/회수 |
| l | 채널 사용자 제한 설정/해제 |


## ⚙️ 실행 방법

```bash
$ git clone https://github.com/eulrho/ft_irc.git
$ cd ft_irc
$ make
$ ./ircserv <port> <password>
```

- 포트: 사용할 포트 번호
- 패스워드: 클라이언트 접속 시 사용할 인증 비밀번호
